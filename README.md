# XPresent 🏍️  
Система онлайн-бронирования услуг (поездки на квадроциклах и туры на эндуро)

## 🚀 Описание проекта
Проект предназначен для онлайн-записи клиентов на услуги площадки.  
Каждая услуга имеет собственную длительность, рабочие часы и независимое расписание.

Клиент выбирает дату, время и указывает свои контактные данные —  
после чего система создает бронь, если выбранный слот свободен.

---

## ⚙️ Технологии
- **Laravel 12**
- **PostgreSQL**
- **Vue 3 + Inertia.js**
- **TailwindCSS**
- **Axios**
- **Docker (опционально)**
